# Installation Guide
## Requirements
- Linux or macOS
- git
- Basic text editor
## Step 1: Clone Repository
```bash
git clone https://github.com/thomaswalton/project.git
```
## Step 2: Install Dependencies
```bash
sudo apt install git vim
```
## Step 3: Configure
```bash
git config --global user.name "Tom W"
git config --global user.email "tomuw9@gmail.com"
```
## Verification
```bash
git --version
```
